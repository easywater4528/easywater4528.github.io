# Jisoo Lee — Portfolio

순천향대학교 사물인터넷학과 **이지수**의 대학 4년 활동 포트폴리오.  
IoT · 무선 네트워크(Wi-Fi 8 / IEEE 802.11bn) · 자율주행 로봇 · AI 헬스케어.

🔗 **Live:** https://easywater4528.github.io/

## 담고 있는 것
- 학년별 타임라인 (연구 · 프로젝트 · 수상 · 교육 · 대외활동)
- 활동별 상세 페이지 — 역할, 과정, 결과, 사진, 시연 영상, 상장, 원본 발표자료(PDF)
- IEEE ICTC 2025 1저자 논문, ICOIN 2027 투고 논문, 졸업작품 TESUNLA, 글로벌 AI 헬스케어 캡스톤(세부) 등

## 구조
```
index.html   페이지 레이아웃 · 스타일 · 라우팅 (단일 파일)
data.js      모든 활동 데이터 (여기만 고치면 내용이 바뀝니다)
assets/      사진 · 썸네일 · 시연 영상
docs/        발표자료 · 논문 · 보고서 원본 (PDF)
```
